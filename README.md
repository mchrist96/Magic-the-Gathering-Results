# Magic: The Gathering Pod Results

Commander pod game tracking for Mitchell, Eric, Hunter, and Harrison. Data exported from the pod's Google Sheet.

## Data files (`data/`)

- **[2026_mtg_tracker.csv](data/2026_mtg_tracker.csv)** — Game-by-game log: each player's placement and deck per game, plus notes and per-game win/last-place flags. 37 games recorded so far.
- **[deck_results.csv](data/deck_results.csv)** — Per-deck average placement and games played (unsorted and sorted views), plus per-player summary stats (average placement, unique decks, win rate, last-place rate).
- **[full_deck_list.csv](data/full_deck_list.csv)** — Every deck by owner with times played, wins, and win rate (grouped by owner and sorted by win rate).
- **[deck_results_5_or_more_games.csv](data/deck_results_5_or_more_games.csv)** — All-time average placement for decks with 5+ games.
- **[color_breakdown.csv](data/color_breakdown.csv)** — Color composition (WUBRG proportions) of Mitchell's decks.

Source: [Google Sheet](https://docs.google.com/spreadsheets/d/1AfJDLmiVCc_Go0tCShl3lHVNXf6w9Bd9z4ATkYC3Kx8/edit)
